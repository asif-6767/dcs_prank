# ⚡ INSTALLATION

### 🔹 ONE BY ONE

```bash
pkg update & upgrade -y
pkg install git
pkg install python -y
git clone https://github.com/asif-6767/dcs_prank.git
cd dcs_prank
python prank.py
```

🔹 ALL IN ONE

```bash
pkg update && pkg upgrade -y && pkg install git python -y && git clone https://github.com/asif-6767/dcs_prank.git && cd dcs_prank && python prank.py
```
